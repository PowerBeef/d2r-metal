# D2R Metal

D2R Metal 是 [D2R Mobile](https://github.com/jhaizhou-ops/d2r-mobile) 的分支，只面向 macOS 与 iOS（Apple 芯片、Metal 4、MetalFX）。本分支的说明只有英文版：[README.md](README.md)。

移植本身（原版程序直接执行、Metal 图形层、触屏操作）是上游的成果；本分支去掉了上游改动游戏规则与经济、或替玩家玩的功能（大秘境、首领连战、极乐世界模式、刷怪积分牌、免费回城、免费鉴定、商人刷新货架、自动喝药、佣兵自动喂药、自动补增益技能、符文之语助手，以及多出来的储藏空间：14 列储藏箱与个人仓库另外四页、珍宝匣、百宝囊与「存放」、编年史仓库），游戏照原版玩。完整的中文介绍见上游的 [README.zh-CN.md](https://github.com/jhaizhou-ops/d2r-mobile/blob/main/README.zh-CN.md)。安卓与鸿蒙版请使用上游。

本仓库不含、也不分发任何游戏内容，请只使用你自己合法拥有的游戏文件。许可证：MIT，见 [LICENSE](LICENSE)。
