# D2R Metal

<p align="center">
  <img src="https://github.com/PowerBeef/d2r-metal/releases/download/assets/banner-hero.jpg" width="100%" alt="D2R Metal">

D2R Metal 是 [D2R Mobile](https://github.com/jhaizhou-ops/d2r-mobile) 的分支，只面向 macOS 27 与 iOS 27 起（Apple 芯片、Metal 4、MetalFX）。本分支的说明只有英文版：[README.md](README.md)。

移植本身（原版程序直接执行、Metal 图形层、触屏操作）是 D2R Mobile 的成果，这份基础功劳归上游。D2R Mobile 还在游戏之上加了自己的玩法与便利功能，供想要的玩家使用；D2R Metal 走另一条路，尽量贴近暴雪发售时的原版，因此不带这些附加内容（大秘境、首领连战、极乐世界模式、刷怪积分牌、免费回城、免费鉴定、商人刷新货架、自动喝药、佣兵自动喂药、自动补增益技能、按难度的掉落过滤、符文之语助手、小地图标注（出入口、小站与任务终点）、两处难度选择（iPhone 底栏、手柄暂停菜单），社区离线补丁里两处影响游戏逻辑的副作用，以及多出来的储藏空间：14 列储藏箱与个人仓库另外四页、珍宝匣、百宝囊与「存放」、编年史仓库）；人数档照原版在选项页「离线难度缩放」那一行改。完整的中文介绍见上游的 [README.zh-CN.md](https://github.com/jhaizhou-ops/d2r-mobile/blob/main/README.zh-CN.md)。安卓与鸿蒙版请使用上游。

**本分支改平台，不改游戏。**

本仓库不含、也不分发任何游戏内容，请只使用你自己合法拥有的游戏文件。许可证：MIT，见 [LICENSE](LICENSE)。
