# D2R Metal

D2R Metal es un fork de [D2R Mobile](https://github.com/jhaizhou-ops/d2r-mobile) dedicado solo a macOS e iOS (Apple silicon, Metal 4 y MetalFX). La documentación de este fork está solo en inglés: [README.md](README.md).

El port en sí (el programa original ejecutándose de forma nativa, la capa gráfica sobre Metal, los controles táctiles y el nuevo contenido de fin de juego) es obra del proyecto original; su presentación completa en español está en el [README.es.md](https://github.com/jhaizhou-ops/d2r-mobile/blob/main/README.es.md) de upstream. Para Android y HarmonyOS, usa el proyecto original.

Este repositorio no contiene ni distribuye contenido del juego: usa solo archivos del juego que poseas legalmente. Licencia: MIT, consulta [LICENSE](LICENSE).
